**MathAI** is a data-driven educational platform combining Mathematics, Data Science, Machine Learning, and Artificial Intelligence to build an adaptive, personalized mathematics tutoring system.

The project also serves as an end-to-end engineering laboratory to study data ingestion, document processing, database architecture, generative AI API integration, and user cognitive modeling.

## 🎯 Project Goals

Build an adaptive AI tutor capable of maintaining a dynamic cognitive model of each student based on behavioral and performance telemetry:
- Solved exercises and problem sets;
- Accuracy, error classification, and misconception patterns;
- Time-to-solution distributions;
- Heuristics and problem-solving strategies;
- Student confidence levels;
- Conceptual justifications;
- Handwritten resolution analysis via multimodal OCR;
- Interactive hint telemetry and progression.

The long-term roadmap focuses on leveraging this behavioral dataset for personalized recommendation engines, **Knowledge Tracing (BKT/DKT)**, multi-step proof evaluation, and custom fine-tuned Machine Learning models.

## 🏗️ Technical Architecture & Design Decisions

A core architectural principle of this system is the strict separation between deterministic computations and semantic interpretations:
- **Python:** Handles deterministic data pipelines: extraction, regex parsing, cleaning, structural validation, deduplication, and database persistence.
- **LLMs / AI APIs:** Restricted exclusively to non-deterministic semantic tasks: mathematical typesetting translation, handwritten proof analysis, cognitive diagnostics, and formative feedback generation.

**Dataflow Pipeline:**
`Exam Datasets / PDFs / Notion` ➔ `Python ETL Pipeline` ➔ `Sanitization & Normalization` ➔ `Semantic AI (LaTeX & Proof Parsing)` ➔ `Relational Storage (SQLite / Turso)` ➔ `Streamlit UI` ➔ `Adaptive Analytics & ML`

## 🛠️ Tech Stack

`Python` · `Pandas` · `NumPy` · `SQLite` · `Turso (Distributed SQLite)` · `Streamlit Cloud` · `Gemini API` · `Hugging Face` · `LaTeX / KaTeX` · `Git / GitHub`

## ✨ Key Implemented Features

- **Offline-First Data Ingestion:** Custom parsers for raw PDF exams and exported Markdown repositories (Notion) from competitive entrance examinations (EFOMM, ESA, CEDERJ), utilizing regex patterns and OCR fallback.
- **Automated Mathematical Normalization:** Targeted LLM prompt engineering to sanitize broken encoding artifacts, extract multi-tier math expressions, and format equations into pristine, standard LaTeX.
- **Hybrid Relational Architecture:** Dual-layer database configuration featuring local SQLite for low-latency batch extraction/ETL and Turso (libSQL over edge) for cloud production deployment.
- **Epistemological Data Segregation:** Clear architectural boundaries between *observed data* (ground-truth behavioral signals from the learner) and *derived inferences* (probabilistic diagnostics generated by AI models).
- **Interactive Cloud Platform:** Full-featured web app deployed on Streamlit Cloud featuring interactive tests, step-by-step diagnostic feedback, and user authentication (live at [mathia.streamlit.app](https://mathia.streamlit.app)).
